# Rentcar - Premium Car Rental & Admin Dashboard Portal

A full-featured car rental application containing both a consumer vehicle browsing portal and a comprehensive administrative dashboard for reservation and fleet management.

## Key Features

### Consumer Portal
- **Vehicle Catalog**: Search and browse available cars with specs, prices, and features.
- **Detailed Car Views**: Interactive page highlighting reviews, sanitization guarantee, and ratings.
- **Booking Engine**: Booking forms with real-time feedback using Toastify notifications.
- **Reviews & Contact**: Interactive review submissions and contact page.

### Administrative Dashboard
- **Analytics Overview**: Main summary metrics (total bookings, revenue, active cars).
- **Inventory Control**: CRUD panel to update fleet vehicles.
- **Reservation Tracking**: Management table for customer booking approvals.
- **Customer Directory**: Customer profiles and payment tracking sheets.
- **System Settings**: Configuration panel for portal metrics.

## Tech Stack
- **Frontend**: React, React Router, React Toastify, Custom CSS design variables.
- **Icons**: React Icons (Fa, Md, Io).

## Getting Started

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```
